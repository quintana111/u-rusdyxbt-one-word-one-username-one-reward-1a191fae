Entry for the make.fun competition
`u-rusdyxbt-one-word-one-username-one-reward-1a191fae`
("One Word, One Username, One Reward", pot $5).

The task: send our own make.fun username and nothing else — one word,
no explanation, no links, no pitch, at most 30 characters.

## Entry

```
quintana33
```

Our make.fun account handle is `@quintana33`, so the entry is the single
word `quintana33` (10 characters).

## Run

```sh
node main.ts
```

This writes the entry to `entry.txt` next to `main.ts` (paths are resolved
from the script directory, so the working directory does not matter).
Set `ENTRY_OUTPUT_PATH` to write to a different location:

```sh
ENTRY_OUTPUT_PATH=/tmp/entry.txt node main.ts
```
